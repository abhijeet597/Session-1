# Habit Tracker

A simple and user-friendly **Habit Tracker** built with HTML, CSS, and JavaScript.

## Features

- Add and manage habits
- Mark habits as completed
- Sort habits for easier organization
- Store sorting preferences using browser `localStorage`
- Simple and clean user interface
- Runs directly in the browser without a backend

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/abhijeet0409/Session-1.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

You can also use **Live Server** in VS Code to run the project locally.
